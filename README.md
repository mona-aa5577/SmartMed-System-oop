# SmartMed-System-oop
"An Object-Oriented Java system designed to improve medication adherence and patient safety, aligned with Saudi Vision 2030 digital health goals."
How to Run
To see the main logic of the system, please check the Main.java file
🚀 Technical Overview
This project implements a comprehensive medical management system using Java. It demonstrates a deep understanding of System Analysis and Software Design Patterns.
🛠️ OOP Principles Applied:
Inheritance: Used in classes like Nurse, Patient, and RemoteDoctor extending the Person base class.
Abstraction: Implemented via abstract class Person to define core entities.
Encapsulation: Managing medical records and visit logs securely.
System Design: Logical flow between mobile clinics, doctors, and patient vital signs.
🇸🇦 Vision 2030 Alignment
Part of my commitment to the National Transformation Program, this system aims to digitize healthcare services and improve the quality of life through smart, reliable software solutions.
